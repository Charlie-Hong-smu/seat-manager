# BoardUI 班级职务

仅本地预览，Zhang 先行，未提交、推送或部署。与“优化座位页面编辑切换”任务协作，沿用其共享动效和学生详情固定外框。

## 使用

- 座位 → 班级职务：班委与其他岗位、课代表、小组长三个页签；新增、改名、删除职位，选择多人任职，补充缺少的常用职位。
- 学生 → 档案 → 班级职务：查看全部现任职务，调整班委/课代表并显式保存；组长、宿舍长显示所属范围。
- 宿舍 → 宿舍成员 → 宿舍长：选择、更换、取消本宿舍负责人。

## 默认目录与边界

默认班长、副班长、学习/纪律/劳动/生活/体育/文艺/宣传委员、团支书、组织委员、心理委员和电教管理员；课代表初始随已有科目目录（默认语数英、物化生、政史地）。以上是可裁剪模板，不要求每个职位都安排人员，不限定一人一职或课代表人数。班级如需日语课代表、图书管理员、值日班长，可自行添加；删除全部默认职位后不会在刷新时重新出现。

模板参考学校公开分工：[苏州市第五中学班干部工作职责](https://sz5z.suzhou.edu.cn/info/1666/3586.htm)列有班长、副班长及学习、宣传、体育、文娱、劳动、生活委员；[中山大学附属中学宿舍长交流](https://fz.sysu.edu.cn/article/5964)体现宿舍成员协调与提醒职责。学校安排存在差异，因此其他岗位采用可编辑模板，不作为全国统一规定。

小组指当前座位布局的组，每组、每宿舍最多一位负责人；调离、归档、删除会解除对应任职，其他有效职务保留。升入新学期保留职位目录，重新安排人选。备份与手动云同步继续走现有数据链路。
