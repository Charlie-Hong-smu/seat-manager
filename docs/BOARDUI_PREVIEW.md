# BoardUI 独立预览

分支：`codex/boardui-preview`。基线：`bf88047`，另复制原工作目录的四份未提交文件（设计规范、SeatBoard 与两份座位动画测试），保留当前座位行为。原目录仍为 main；未推送、合并或部署。

## 已实现

- 从 BoardUI MCP 获取真实主题、字体、按钮和分段控件源码。主题合并到唯一的 `src/styles/theme.css`，业务通过 `ui.tsx` 继续调用。
- 按钮适配 React 18 forwardRef；分段控件保留 group / aria-pressed、单选值与业务回调，并使用 React Aria 键盘操作。
- 全站业务组件统一中性、强调和状态颜色，以及常用复合字体样式；侧栏、工作面、卡片、普通表单、日期、浮层与工具栏采用统一视觉基础。
- 通用按钮去掉位移与缩放，浮层进入采用短距离淡入缩放；座位拖拽、碰撞、吸附、候补顺序、姓名转移与评语文字流算法保留。
- 新增 tailwind-merge 3.6.0 与 react-aria-components 1.17.0。Vitest 与 Vite 使用相同源码别名。

## 边界

这是可运行的广泛视觉迁移预览，并非所有控件都改用 BoardUI 实现。下拉搜索、中文日期、确认/抽屉、复杂表格、图表与业务动画仍由原实现承担，并已适配主题。未安装 Pro、未引入模板后端、未升级 React、未启用暗色。已补充下述主要页面人工验收与完整浏览器套件；仍不代表每一业务数据组合、真实 AI 服务或全设备性能均已验收。本分支不作为上线授权。

## 打开

在本目录的 frontend-react 运行 `pnpm dev --host 127.0.0.1 --port 5188 --strictPort`，打开 `http://127.0.0.1:5188/seat-manager/`，使用“进入本地预览”。该端口的数据与原站点按浏览器 origin 隔离。

本次修复：旧式紧凑座位从固定行高改为容器适配，八排与讲台在目标尺寸完整显示；共享 ToolDrawer 增加 150ms 退出保留、退出期间 inert 与焦点返回；窄分段控件允许换行；打开同步面板时收起账户菜单，并补齐关闭按钮名称。

AI 按用户要求改为 BoardUI neutral 石墨灰色阶，覆盖入口、提示、生成按钮、加载线与评语。共享生成面板采用白底、静态图标及单色细线；助手与结果采用短距离淡入和轻微模糊，移除旋转光环、扫光、发光脉冲和选中文字彩色闪动。评语文字流与教师确认逻辑保留。这是按 BoardUI 视觉规范适配原业务动效，不声称存在上游同名 AI 业务组件。

验证记录：完整浏览器套件 Zhang 33/33、Commercial 8/8 通过；后续同步入口小修复专项 2/2、新 AI 配色专项 4/4 通过。lint、strict typecheck、check:design、184 项单元测试与 diff 检查通过；覆盖率与前述门槛一致，Worker 23/23。两版构建、体积及 Commercial 生产包检查通过，入口 gzip 194.7 KiB、precache 1.65 MiB。

边界：AI 返回由 e2e 模拟，未调用真实 AI 服务；没有执行正式云同步。手动拖拽曾被自动审批阻止（可能改写数据），因此未手动执行，相关行为依据隔离自动化结果。同步面板点击初次被阻止，源码证实仅设置打开状态后获准查看。没有逐帧性能量测，也未穷尽所有数据、屏幕与弹窗组合；独立旧弹窗仍可能保留不同的退出节奏。
