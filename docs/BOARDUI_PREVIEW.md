## 早前状态：已收尾并停止（2026-09-08）

用户在用量重置后明确授权修复剩余两项问题并完成验收。此次仅修复键盘边界，没有继续扩展视觉替换，也没有推送、合并或部署。

- 组名输入回车提交后，焦点立即返回触发按钮；未消费的回车默认动作会再次激活该按钮。共享 PromptDialog 现在阻止已处理回车的默认动作和冒泡，同时保留中文输入法组合输入、校验、点击确认与取消行为，覆盖所有共用文本弹窗。
- BoardUI Select 鼠标打开后可能仍聚焦触发按钮，仅在菜单内容上拦截 Esc 无法覆盖。现在在展开期间对触发按钮和菜单内部的 Esc 进行捕获，关闭当前下拉并返回焦点，不影响外层抽屉或其他浮层。空值选项、连续开合和学生草稿保留均经浏览器验证。

本轮累计接入官方 StatCards、Input、Textarea、Select、Checkbox、Chip、Tooltip、AgentThinking 及依赖源码，适配 React 18。今日班务重组为统计、事项列表、课表与快捷操作；任务和出勤复用统计卡片；作业、快捷记录、学生工具、跟进、关联处理结果、AI 教师补充与共享搜索等统一表单视觉。出勤与作业登记使用白底表面，状态色保留在标签与图标。

动画采用官方单色点阵等待、短距离抽屉进入、150ms退出保留与 inert、240ms评语工作台同步进入；减少动态效果时停止点阵刷新和动画。保留座位拖拽、文字选区、草稿和教师确认业务机制。
