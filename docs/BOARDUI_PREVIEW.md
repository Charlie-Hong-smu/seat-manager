# BoardUI 独立预览

## 当前状态：按用量重置要求暂停（2026-09-08）

本轮为未完成验收的检查点，不可作为发布版本。检测到账户 usedPercent 从 78% 降到 1%，且重置时间改变，按用户“恢复到百分百就停”的要求停止后续修改和测试。

本轮增加 BoardUI 官方 StatCards、Input、Textarea、Select、Checkbox、Chip、Tooltip、AgentThinking 及其依赖源码，并适配 React 18。今日班务重组为统计、事项列表、课表与快捷操作；任务和出勤统计复用 StatCards。作业、快捷记录、学生工具、跟进、关联处理结果、AI 教师补充、共享搜索与文本输入弹窗等改用实际字段组件。普通下拉接入官方 Select；可搜索下拉、学生选择器使用同一菜单视觉规范。出勤与作业登记统一白底，状态颜色保留在标签和图标。

动画新增：官方单色点阵等待；系统 reduced motion 改变时停止点阵计时；抽屉采用 12px 短距离进入和 150ms 退出；通用弹窗保留退出内容、退出期间 inert，修复 autoFocus 抢占原始焦点导致无法返回的问题；评语工作台改成 240ms 同步淡入和 150ms 退出，取消原有 480ms 错峰位移。文字选择、草稿与教师确认逻辑保留。

已验证：设计检查、lint、strict typecheck、41 个测试文件共 190 项通过；核心覆盖率维持语句77.25%、分支62.83%、函数78.52%、行80.5%；Worker 23 项通过。此次中途 Zhang 构建体积入口203.2 KiB、precache1.83 MiB，满足预算。实际预览检查今日、复盘抽屉、任务与作业、状态下拉、出勤和评语工作台。早期完整浏览器套件33+8通过；后续控件变更的 Zhang 35项中32项通过、3项失败，不能沿用早期结果声明最新版通过。

最近专项5项中3项通过：评语工作台新开合、选中文字滚动定位、AI等待及减少动态效果；仍有2项未通过：①组名输入 Enter 后可能重新打开弹窗（最后截图显示已归一化为“第7组”，需要检查焦点返回与键盘事件重入）；②连续开合性别下拉后 Esc 会使学生抽屉关闭，需要先确认当时下拉确实已展开，再定位快速重开和事件层级。已加入下拉展开断言但因用量重置尚未执行。不得声称这两项已修复。

## 已实现

- 从 BoardUI MCP 获取真实主题、字体、按钮和分段控件源码。主题合并到唯一的 `src/styles/theme.css`，业务通过 `ui.tsx` 继续调用。
- 按钮适配 React 18 forwardRef；分段控件保留 group / aria-pressed、单选值与业务回调，并使用 React Aria 键盘操作。
- 全站业务组件统一中性、强调和状态颜色，以及常用复合字体样式；侧栏、工作面、卡片、普通表单、日期、浮层与工具栏采用统一视觉基础。
- 通用按钮去掉位移与缩放，浮层进入采用短距离淡入缩放；座位拖拽、碰撞、吸附、候补顺序、姓名转移与评语文字流算法保留。
- 新增 tailwind-merge 3.6.0 与 react-aria-components 1.17.0。Vitest 与 Vite 使用相同源码别名。

## 边界

这是可运行的广泛视觉迁移预览，并非所有控件都改用 BoardUI 实现。下拉搜索、中文日期、确认/抽屉、复杂表格、图表与业务动画仍由原实现承担，并已适配主题。未安装 Pro、未引入模板后端、未升级 React、未启用暗色。已补充下述主要页面人工验收与完整浏览器套件；仍不代表每一业务数据组合、真实 AI 服务或全设备性能均已验收。本分支不作为上线授权。

## 打开

在本目录的 frontend-react 运行 `pnpm dev --host 127.0.0.1 --port 5188 --strictPort`，打开 `http://127.0.0.1:5188/seat-manager/`，使用“进入本地预览”。该端口的数据与原站点按浏览器 origin 隔离。
