# BoardUI 独立预览

分支：`codex/boardui-preview`。基线：`bf88047`，另复制原工作目录的四份未提交文件（设计规范、SeatBoard 与两份座位动画测试），保留当前座位行为。原目录仍为 main；未推送、合并或部署。

## 已实现

- 从 BoardUI MCP 获取真实主题、字体、按钮和分段控件源码。主题合并到唯一的 `src/styles/theme.css`，业务通过 `ui.tsx` 继续调用。
- 按钮适配 React 18 forwardRef；分段控件保留 group / aria-pressed、单选值与业务回调，并使用 React Aria 键盘操作。
- 全站业务组件统一中性、强调和状态颜色，以及常用复合字体样式；侧栏、工作面、卡片、普通表单、日期、浮层与工具栏采用统一视觉基础。
- 通用按钮去掉位移与缩放，浮层进入采用短距离淡入缩放；座位拖拽、碰撞、吸附、候补顺序、姓名转移与评语文字流算法保留。
- 新增 tailwind-merge 3.6.0 与 react-aria-components 1.17.0。Vitest 与 Vite 使用相同源码别名。

## 边界

这是可运行的广泛视觉迁移预览，并非所有控件都改用 BoardUI 实现。下拉搜索、中文日期、确认/抽屉、复杂表格、图表与业务动画仍由原实现承担，并已适配主题。未安装 Pro、未引入模板后端、未升级 React、未启用暗色。尚未逐屏逐状态完成人工视觉验收，也未运行全部浏览器套件；本分支不作为上线授权。

## 打开

在本目录的 frontend-react 运行 `pnpm dev --host 127.0.0.1 --port 5188 --strictPort`，打开 `http://127.0.0.1:5188/seat-manager/`，使用“进入本地预览”。该端口的数据与原站点按浏览器 origin 隔离。
