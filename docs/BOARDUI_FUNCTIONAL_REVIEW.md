# BoardUI 功能审计与修复

日期：2026-09-22。范围：本地 `codex/boardui-preview`，与“优化座位页面编辑切换”任务分工协作。主目录已有改动、已验收的座位过渡、样式与动画算法均由原任务保持；本轮不提交、不推送、不部署。

## 已修复

| 问题 | 影响与修复 |
| --- | --- |
| UTC 时间戳截取日期 | 东八区凌晨通知写回后仍被判断为“昨天通知”，可反复触发；周报完成量、历史日期和来源速览也会错日。统一安全本地日期转换并提取待通知任务选择器，保留原始 ISO 时间戳与旧日期字段。 |
| 草稿存储异常回流 | 写入失败后重新打开会读回旧值，删除失败后已提交草稿会复现。统一内存降级、清空标记和作用域检查，并修复同一事件中清空后函数式更新仍使用旧值、null 对象缓存造成表单崩溃的问题。覆盖所有使用该共享 hook 的任务、作业、快捷记录、宿舍、班费和周报表单。 |
| 标签删除后展示残留 | 最后一个行为标签被移除后仍沿用旧显示标签；纯手动学科标签也没有按修改投影。按各类别修改前后 ID 派生显示值，保留自动标签和仅有文字的旧数据类别。 |
| 宿舍误报待处理 | 没有处理措施的表扬/备注也进入学生关注和周报待处理量。共享谓词只统计实际未完成的处理措施，兼容历史归档事件。 |

本轮以共享逻辑收敛重复判断；没有为减少行数重写整个应用壳，也没有复制第二套业务状态。UI 仅对通知选择器、学生关注谓词和时间线日期进行局部接入，不增加控件、色彩或动效。

## 验证

新增 17 项单元/组件回归，覆盖草稿存储失败、班级/表单隔离、清空与重开、标签清空、跨日通知、周报、旧数据历史、来源速览和宿舍事件。草稿与标签的 7 个用例在原实现中明确失败、修复后通过。浏览器补充 `functional-state.spec.ts`，两版测试入口均包含；测试中的授权与通知替身仅位于 e2e。

最终验证：设计契约、lint、strict typecheck、合并树 211 项前端测试与覆盖率门槛、23 项 Worker 测试均通过。日期 5 项用例还单独在 America/Los_Angeles 运行通过；全套前端测试在 Asia/Shanghai 运行。两版构建与 check:size 均通过，入口 JS gzip 204.7 KiB、最大异步 JS gzip 110 KiB、PWA precache 1.86 MiB；Commercial check:production 通过，9 个 JS 文件没有测试授权或模拟响应。

浏览器分批覆盖 Zhang 9 个、Commercial 7 个相关用例：学生编辑与刷新、归档学生撤销、座位布局取消、评语内关注/时间线预览、作业登记、整柜/考试/云同步模拟与工作区隔离、共同事项与逐人催缴，以及新增的凌晨通知和草稿异常。原失败项在共享修复后仅做针对性复验，最终通过；Commercial 减少动态效果的座位往返检查亦通过。测试使用独立班级、测试授权响应和 4293/4294 端口，不读取或修改正式教师数据，不调用真实 AI 服务。

协作过程中确认并交给动画任务修复了 ToolDrawer 低于顶栏造成关闭按钮被遮挡的问题；保留 AI 抽屉的显式层级。减少动态效果下 .01ms 动画仍短暂处于 running 的问题，也由动画任务按既有合同显式禁用对应座位动画。普通座位过渡保持既有实现；没有重新做逐帧验收。
