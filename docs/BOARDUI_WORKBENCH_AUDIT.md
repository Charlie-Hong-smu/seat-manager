## 这轮落实的改进

| 已确认问题 | 完成的处理 |
| --- | --- |
| 名单重排绕过锁定，手动分配未验证原座位锁定 | 同一锁定约束覆盖名单重排、交换和指派；锁定空座也保留。 |
| 撤销只记录学生顺序，改布局/恢复快照后无法完整恢复 | 统一保存布局、顺序、锁定及受影响组长；只撤销座位领域，保留之后的档案/班务修改和新任命，离班学生不恢复入座。 |
| 历史快照仅按姓名匹配，同名或改名会错配 | 新快照保存稳定学生 ID 与锁定，同时保留姓名字段；旧快照只匹配唯一姓名，歧义留空并提示。默认布局可以从自定义布局正确恢复。 |
| AI 服务和抽屉生成后直接写正式评语 | 所有生成入口统一返回候选并缓存本机草稿，老师保存才写正式记录；增加草稿/已保存标识和批量确认保存。 |
| 异步结果在切换学生、离开页面后仍可生效 | 共享请求取消与作用域校验；批量生成检查编辑版本，保留请求期间的手工修改。暂停保留队列，离开页面停止请求，回到工作台可继续。 |
| 每名学生的自定义字数未正确恢复，手工正文未标记为已编辑 | 字数/风格与正文按学生缓存；支持直接输入与保存并下一位，刷新仍恢复草稿。处理旧记录无时间戳及同毫秒素材保存造成草稿回退的问题。 |
| 损坏工作区在控制器读取作用域时异常，无法进入恢复页面 | 读取作用域失败时保留原始数据、禁用持久化并交由既有恢复入口处理；老师明确恢复前不覆盖文件柜。 |
| 评语单独保存后，被主页面旧状态自动保存覆盖 | 局部保存桥接同步评语和标签增减到唯一控制器；即时刷新、随后调座位和工作区切换均读取最新状态，保留尚未落盘的其他编辑。 |

## 维护与兼容

提取 `seatWorkflow`、`useScopedRequest` 和 `commentPersistence`，让座位恢复、异步结果失效和兼容保存各有单一入口；不为了缩短文件而重写页面结构。保留协作任务的评语批量读取、名单样式、工作区动画和 AI 浮窗修改。

快照只添加可选字段，旧文件柜、单班导入、备份/手动云同步键与载荷继续兼容。未增加 Worker 路由、外部账号连接或自动教师数据提交。评语缓存仍是本机草稿；正式评语才属于班级数据中的已保存内容。座位历史恢复是老师明确选择整份快照，因此允许恢复快照自身的布局及锁定；它不同于必须绕开锁定座位的名单重排。
