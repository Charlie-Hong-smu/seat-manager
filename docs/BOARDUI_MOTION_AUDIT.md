# BoardUI 连续动效排查

范围：`codex/boardui-preview` 本地预览。以已验收的座位布局过渡为基准，消除硬切、重复入场、收尾跳动；不改数据提交、排序规则、授权或发布流程。

| 场景 | 排查结果与处理 |
| --- | --- |
| 侧栏工作区导航 | 原来仅新页淡入，旧页立即消失；改为同一固定工作面内连续交接。 |
| 学生详情左右换人、直接选人、详情页签 | 原来重播内容入场且测量弹窗高度，形成跳动；保留同一外壳和滚动容器；按当前内容平滑伸缩，正文原位交接，姓名保留方向。 |
| 任务/作业、成绩概览/题目分析、成绩页签、历史两种视图、班费流水/收缴 | 接入共享内容过渡，页签及工具条留在原位。 |
| 出勤/作业快速与详细、作业生命周期 | 内容连续交接；筛选和名单变动按稳定 ID 让位，状态登记不自动重排。 |
| 跟进结果、出勤行内详情、抽签历史、题目薄弱学生 | 按实际内容高度展开和收起，收起结束前保留内容。 |
| 班费关联学生、宿舍责任人 | 去除固定 max-height 动画，避免名单过长被截断；关闭控件禁止焦点进入。 |
| 评语参数、老师补充、评价维度、跟进面板、自定义字数、AI 上下文 | 复用高度过渡；长列表原有滚动上限保留。 |
| 事项速览 | 取消依赖 transitionend 才卸载的单独生命周期；减少动态效果和快速重开都能清理。 |
| 日期月份 | 日历网格连续交接，日期选择和约束规则不变。 |
| 弹窗/工具抽屉 | 保留关闭前内容；反向操作从当前透明度/位置继续，避免退出或重开时先回到关键帧起点。补齐评语导出及清空草稿时的任务抽屉退场。全局抽屉层级统一置于顶栏之上，避免关闭按钮被顶栏遮挡；AI嵌套抽屉保留独立层级。 |
| 今日待办、任务、出勤/作业名单、历史快照 | 同一共享列表让位；删除项以无交互副本退场，真实业务行正常卸载；今日完成任务不再等待旧 max-height 动画才提交，提交期间防止重复点击。 |
| AI 跟进/趋势结果 | 原 900ms 高度动画与入场叠加；缩短至统一节奏并去除重复入场。生成进度、文字流和老师确认边界保留。 |

保留已经针对几何实现的座位切换/拖放/分组、姓名转移、侧栏宽度、评语工作台分栏、成绩工具区变形、分段滑块及下划线指示器。宿舍详情和评语换学生沿用已有浏览器 View Transition。加载指示、实时状态文字、错误消息立即反馈；不为每个字符或每次输入重复播放动画。

共享实现从 `ui.tsx` 导出，实现位于 `motion.tsx`，样式只在 `theme.css`。切换动画用不可交互 DOM 视觉副本，不二次挂载 React 业务组件；当前层始终不透明，避免白闪。临时动画和副本在完成、被打断、组件卸载时清理。收起区的间距放在内部，禁止用任意 max-height 模拟内容高度。

验证入口：`pnpm exec playwright test app-motion.spec.ts`，可通过 `E2E_PORT` 覆盖默认测试端口，避免并行任务误用旧预览。测试涵盖普通/减少动态效果、学生左右与页签切换的外框和焦点、快速反向、导航后清理、数据不变、行内收起和名单筛选。共享组件回归涵盖退出保留、惰性内容、重复 ID、取消与卸载。无需重复逐帧验收已经通过的座位过渡。

### 主导航、内嵌评语及 AI 开启性能（2026-09-22）

主导航即时选中，右侧保留原画面约 90ms 后按导航顺序做 400ms / 40px 纵向交接；新内容提前挂载并保持不透明，转场结束前 inert、aria-hidden。慢模块保持旧画面直到实际内容就绪，快切取消旧等待并从当前画面继续。评语改为主工作区 region，保留顶栏、主工作面外框，进入自动收起主侧栏、离开恢复原状态；三栏按容器宽度连续分配。导出仍通过顶层 portal 展示，学生详情的“离开评语工作台”提示独立于浮层层级，保留上下文预览与草稿。

性能采样使用独立 Chromium、60 名合成学生、1310×800、相同开发服务及热模块，分别连续进入评语三次。优化前首次绘制间隔 59.8 / 53.2 / 53.6ms，优化后 45.0 / 35.9 / 36.6ms；每次本地 getItem 从 198 降至 80，子树动画查询从 927 降至 1，三次入口中观测到的 56 / 51 / 51ms 长任务消失。数据是本机诊断样本，不代表所有设备帧率。原始数值保存在 `output/motion-performance-20260922.json`。仍保留侧栏宽度、内容位置与透明度动画。

原因和修复：评语按学生循环读取整个班级作用域及持久化资料，现改为每批解析一次，保留最新时间戳、未保存草稿和班级隔离语义，存储不可用时仍返回内存草稿；学生列表引用稳定，初始补充说明区域直接使用正确状态，减少进入后再次渲染。视觉副本不再为每个后代查询活动动画及重写所有未变属性，SVG 引用隔离、输入值和中途动画位置继续保留。

AI 原先冷加载会先出现完整白色加载框，然后正式面板从透明再次进入；独立 rendered/transitionState 的计时也与共享反向动画重复。改为热模块同步复用、冷加载延迟显示小型可取消状态，正式表面统一由 DialogPresence 处理一次入场与退出。去掉 scrollIntoView，焦点使用 preventScroll，对话滚动仅操作内部容器。检查覆盖首次/再次开启、慢加载取消后不得迟到弹出、快速关闭重开、减少动态效果、焦点返回与主页面位置不变。
